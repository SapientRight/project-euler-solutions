# Project Euler Solutions

A collection of Project Euler problems I have solved using C++.The problems are organized into folders by number, and the approach used for each solution is briefly explained.

## Structure
- `problem_001/` - Multiples of 3 and 5
- `problem_002/` - Even Fibonacci Numbers
...

## How to run
g++ -o solution problem_XXX/main.cpp && ./solution
